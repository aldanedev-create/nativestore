# Expense Desk

Generated by NativeStore. Run `nativestore dev` for the Tauri window, or
`nativestore dev --browser` for an explicit browser debugging session.
Run `nativestore test` to test Python behavior without a window.
On Windows, install NativeStore's packaging extra and Tauri build prerequisites,
then run `nativestore build`.

Edit `main.py` for registered commands, `pages/*.py` for pages,
`templates/` for JinjaX components and `static/` for JavaScript/CSS.
SQLite records live in the user's application data directory, outside the install.
The starter works without third-party browser assets. Add optional libraries with
`nativestore add htmx`, `nativestore add alpine`, or `nativestore add lucide`;
include the resulting `/static/vendor/*.js` files in Layout.html when using them.

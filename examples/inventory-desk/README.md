# NativeStore htmx-alpine starter

Run `nativestore dev` for a native window or `nativestore dev --browser` for browser debugging. Run `nativestore test`.

Python/JinjaX handles forms; HTMX and Alpine are optional.

Visit `/inventory` to add, list and delete stock. It is an explicitly mounted blueprint with SQLite persistence and HTMX fragments. Validation also works with ordinary full-page form submissions.
